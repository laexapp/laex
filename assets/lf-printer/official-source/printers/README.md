# Originales oficiales de impresoras

Coloque aqui los PNG o WebP maestros con los nombres definidos por LF-PRINTER:
`{modelo}-transparent.png` o `{modelo}-transparent.webp`.
El comando `npm run media:sync` valida transparencia y resolucion, conserva una
copia por checksum y publica las variantes sin cambiar componentes.

Requisitos: lado mayor de 2000 px como minimo y fidelidad oficial. El original
se conserva por formato y checksum. WebP se normaliza localmente a PNG antes del
proveedor. Ningun recurso insuficiente se amplia artificialmente mediante IA.
