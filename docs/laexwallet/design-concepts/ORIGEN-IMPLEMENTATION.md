# Origen — Android 0.1.4-testnet

Selected by the owner from the three visual concepts. Implemented with native
Android controls, preserving the previously approved LAEX logo, the current
wallet and authentication flow. The dark green gradient, contour lines,
rectangular action tiles, balance, network row and backup card follow concept 01.
Existing accounts show unlock actions rather than create-account actions.
The testnet disclosures remain visible. No absolute security promises from the
concept board are used in the application.

Artwork: `android/laexwallet/app/src/main/res/drawable-nodpi/origin_hero.png`.
Generated with the built-in image generation tool using `01-origen.png` as the
reference. The final prompt was:

> Extract and faithfully recreate ONLY the welcome illustration seen in the LEFT PHONE of this approved Origen wallet reference: the identical sculptural satin mint-green ribbon folded into a triangular protective shelter with open middle, around a small softly luminous warm ivory pearl, resting on dark mossy volcanic rock, a few blurred deep green leaves at the sides. Produce a standalone landscape 3:2 raster illustration for a real mobile app, no phone frames, no words, no letters, no logo, no interface, no buttons, no board typography. Keep the exact geometry, green material and quiet luxury atmosphere of that sculpture, not a new symbol or different concept. Subject centered and completely visible, occupies central 70% width, compact rock platform lower quarter, softly lit from upper left. Edges and top fade smoothly into solid near-black forest #07110D, so the illustration can blend naturally into the app background. Highly detailed but subtle, faithful to the reference, no extra objects.

Layout verification: Robolectric native rendering on API 35, widths 360/393dp,
normal and enlarged text. These are simulated native renders, not a hardware
security audit. Device-specific appearance remains subject to Samsung settings.
