# Centro de Aprendizaje

La documentación del producto se modelará como contenido estructurado para ser consumido por la interfaz, búsqueda y un futuro asistente conversacional.

Cada lección debe incluir: identificador estable, versión, audiencia, objetivo, explicación, cuándo usar, ejemplo, recomendación, acciones relacionadas, preguntas frecuentes y enlaces internos. El texto nunca debe asumir que el workspace pertenece a LAEX.

Fase 1 incluye introducción, workspaces, canales, análisis IA, campañas y analytics; recorrido guiado repetible; ayuda contextual por pantalla; y casos para creador, empresa, academia, podcast, comunidad y proyecto de inversión.

Para IA conversacional futura, la fuente de verdad serán estas unidades versionadas. El asistente deberá citar la lección y versión utilizada, respetar permisos del workspace y nunca inventar capacidades que el tenant no tenga habilitadas.
